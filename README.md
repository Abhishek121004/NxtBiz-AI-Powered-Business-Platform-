# 🚀 NxtBiz – AI-Powered CRM & Operations Platform

NxtBiz is a full-stack business operations platform inspired by modern CRM solutions like Salesforce and HubSpot. It provides centralized management for customers, tickets, invoices, emails, workflows, and analytics through an intuitive dashboard.

## ✨ Features

### 📊 Executive Dashboard
- Business health monitoring
- Analytics and performance metrics
- Interactive charts and visualizations
- Real-time operational insights

### 👥 User & Customer Management
- User management system
- Customer profiles and records
- Role-based access control (RBAC)

### 📧 Email Management
- Email tracking and organization
- Communication workflows

### 📅 Meetings
- Schedule and manage meetings
- Activity tracking

### 💰 Invoice Management
- Invoice creation and tracking
- Financial overview

### 🎫 Ticketing System
- Support ticket management
- Open and closed ticket tracking

### 📄 Reports
- Business reports and analytics
- Data-driven insights

### 🔄 Workflow Automation
- Custom workflows
- Process management

### 🤖 AI Control
- AI-powered operations support
- Intelligent business assistance

### 🌙 Theme Support
- Light mode
- Dark mode

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/Abhishek121004/NxtBiz-AI-Powered-Business-Platform.git
```

## Navigate to the Project

```bash
cd NxtBiz-AI-Powered-Business-Platform
```

---

## Frontend Setup

```bash
cd client
npm install
npm run dev
```

Runs on:

```text
http://localhost:5173
```

---

## Backend Setup

```bash
cd server
npm install
npm run dev
```

Runs on:

```text
http://localhost:5000
```

---

# 🌐 Environment Variables

### Server

Create a `.env` file inside the server directory.

```env
PORT=5000

MONGODB_URI=

JWT_SECRET=

REDIS_URL=
```

### Client

Create a `.env` file inside the client directory.

```env
VITE_API_URL=http://localhost:5000/api
```
